# Лендинг частного фотографа

Одностраничный продающий сайт (лендинг) для частного фотографа. Чистый HTML + CSS + ванильный JS, без сборщиков, фреймворков и зависимостей.
![Скриншот главной страницы](images/screenshot.png).

## Решаемая задача

Привести посетителя к заявке на съёмку. Страница построена как воронка:

1. **Зацепить** — hero-блок с обещанием «настоящих эмоций» и цифрами срока (48 часов до первых кадров).
2. **Показать боль** — блок «Боли»: скованность перед камерой, стресс организации, однотипные фото.
3. **Дать решение** — блок «Как это будет»: живая съёмка без позирования, полная организация под ключ, авторский взгляд.
4. **Доказать** — галерея «до/после», рассказ о фотографе, прозрачная таблица цен, реальные отзывы.
5. **Призвать к действию** — контакты, кнопки «Забронировать созвон» и «Забронировать дату», модальная форма заявки.

## Пользователь

- **Целевая аудитория** — люди, которые хотят личную фотосъёмку (портреты, пары, семьи, беременность) и боятся камеры/организационного стресса.
- **Мотив** — получить живые, «свои» кадры без позирования и лишней беготни.
- **Цель визита** — узнать условия и оставить заявку: записаться на 15-минутный созвон или забронировать дату.

## Состав проекта

```
index.html            — вся разметка страницы
css/style.css         — все стили (токены цветов/шрифтов в :root)
js/config.js          — единственный файл с данными сайта
js/script.js          — вся логика страницы
apps-script/Code.gs   — код приёма заявок для Google Apps Script
assets/img/           — SVG-плейсхолдеры фото и favicon
AGENTS.md             — правила работы над проектом
```

### Блоки страницы (`index.html`)

Шапка с навигацией и бургером → hero → «Боли» → «Как это будет» → Галерея → «Обо мне» → Цены → Отзывы → Контакты → модальное окно формы → подвал.

### Где править данные

Всё содержимое (имя, город, контакты, цены, фото, отзывы, SEO, форма) лежит в **`js/config.js`**. HTML-разметку трогать не нужно — значения подставляются скриптом на лету.

- `name`, `role`, `city` — кто вы и где снимаете
- `telegram`, `whatsapp`, `calendarUrl` — контакты и ссылка на календарь
- `prices` — форматы и стоимость съёмок
- `photos` — кадры галереи (и пары «до/после»)
- `reviews` — отзывы клиентов
- `form.endpoint` — куда уходят заявки

## Как устроена форма заявки

- Модальное окно `<dialog id="lead-modal">` открывается кнопками `data-modal="call"` (созвон) и `data-modal="date"` (дата).
- Поля: имя, фамилия, email, чекбокс согласия + скрытое honeypot-поле `website` против ботов.
- Валидация и отправка — в `js/script.js`; тексты — объект `LEAD_COPY`.
- Отправка POST на `form.endpoint` из `js/config.js`. Если endpoint пустой — демо-режим: заявка сохраняется только в `localStorage`.

### Подключение приёмника заявок

Подробная инструкция — в `js/config.js`. Поддерживаются варианты:

- **Google Таблица** через Apps Script (код в `apps-script/Code.gs`) — бесплатно, без сервера.
- **Web3Forms** — без кода и регистрации.
- **Formspree / Getform / Mailchimp** — по своему URL.
- **Свой сервер / Serverless** — любой URL, принимающий POST.

## Стиль оформления

- **Палитра** — тёплые neutrals: фон `#f7f3ed`, текст `#1c1712`, тёмные секции `#17130f`, акцент-охра `#a9713c`.
- **Шрифты** — заголовки: Cormorant Garamond (serif), текст: Manrope (sans); есть системная запасная пара.
- **Вид** — спокойный и «воздушный»: много отступов, скругления 18/12px, лёгкие тени, плавное появление блоков при скролле.
- **Адаптив** — от 320px, контейнер 1200px, минимальный тап-таргет 44px.

## Запуск

Сборка не нужна — достаточно открыть `index.html` в браузере. Для корректной загрузки шрифтов и данных рекомендуется локальный сервер, например:

```bash
python -m http.server
```
