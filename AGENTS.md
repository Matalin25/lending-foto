# AGENTS.md — правила работы над сайтом

## Что это за сайт
- Одностраничный лендинг частного фотографа (продающая страница-воронка).
- Для кого: потенциальные клиенты съёмок (пары, семьи, портреты) — цель: заявка на созвон или бронь даты.
- Язык интерфейса — русский. Без сборщиков, без фреймворков: чистый HTML + CSS + ванильный JS.

## Из чего состоит
- `index.html` — вся разметка: шапка, hero, блоки «Боли», «Как это будет», галерея, обо мне, цены, отзывы, контакты, модальное окно формы, подвал.
- `css/style.css` — все стили (токены цветов/шрифтов в `:root`).
- `js/config.js` — **единственный файл для данных**: имя, город, контакты, цены, фото, отзывы, SEO, настройки формы. Здесь же инструкция по подключению приёмника заявок.
- `js/script.js` — логика: подстановка конфига, галерея «до/после», таблица цен, отзывы, появление блоков, шапка/бургер, форма заявки.
- `apps-script/Code.gs` — код для Google Apps Script (приём заявок в Google Таблицу), вставляется в таблицу, не в сайт.
- `assets/img/` — SVG-плейсхолдеры фото и favicon.
- `*.doc` — рабочие документы, к коду сайта отношения не имеют.

## Стиль оформления
- Палитра: тёплые neutrals — фон `#f7f3ed` (paper), текст `#1c1712`, тёмные секции `#17130f`, акцент (охра) `#a9713c`, мягкий акцент `#d9b98f`.
- Шрифты: заголовки — Cormorant Garamond (serif), текст — Manrope (sans); запасная системная пара прописана в CSS.
- Общий вид: спокойный, «воздушный», много отступов, скругления 18/12px, лёгкие тени, плавное появление блоков при скролле (`.reveal`).
- Контейнер 1200px, адаптив от 320px, минимальный тап-таргет 44px.

## Как устроена форма заявки
- Модальное окно `<dialog id="lead-modal">` в `index.html`, открывается кнопками с `data-modal="call"` (созвон) и `data-modal="date"` (дата).
- Поля: имя, фамилия, email, чекбокс согласия + honeypot-поле `website` против ботов.
- Валидация и отправка — в `js/script.js` (`initLead`, `sendLead`); тексты кнопок/сообщений — объект `LEAD_COPY`.
- Отправка POST на `SITE.form.endpoint` из `js/config.js` (сейчас Google Apps Script → Google Таблица). Если endpoint пустой — демо-режим (заявка только в localStorage).
- Для Google Script используется `mode: 'no-cors'` и `Content-Type: text/plain` — не менять без нужды.

## Правила работы
- **Не менять тексты и структуру блоков без просьбы пользователя.** Никаких переписываний заголовков, описаний, порядка секций.
- **Перед большими изменениями сначала спрашивать** (новые секции, рефакторинг, смена стилей/шрифтов, подключение новых сервисов).
- Данные (имя, город, цены, фото, отзывы, контакты, форма) править только в `js/config.js`, не размазывать по HTML.
- Не трогать `apps-script/Code.gs` без просьбы; не вставлять туда код сайта.
- Сохранять существующий стиль кода: комментарии на русском, BEM-классы, без зависимостей и сборщиков.
- Проверять адаптив и доступность (aria-атрибуты, фокус, размер тапов) после правок.
- Писать кратко, по-русски, отвечать списками.
